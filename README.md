# 座禅チェック（プロトタイプ）

スマホのカメラに映った人が **座禅のポーズ** をしていると、画面上部に **緑の ⭕️** を表示する Web アプリです。
Android の Chrome で動作します。映像は端末内（ブラウザ）だけで処理し、サーバーには送りません。

## 使い方

1. アプリを開くとカメラが起動します（初回はカメラの許可を求められます）
2. スマホを体の **正面・床に近い高さ** に置き、全身が映るようにします
3. 座禅を組むと、上に緑の ⭕️ が出ます。外れているときは直すポイントを日本語で表示します
4. 「カメラ切替」で前面/背面カメラを切り替え、「詳細」で各チェック項目の値を確認できます

## 判定の内容（`src/poses/zazen.ts`）

胴の長さ（肩の中点〜腰の中点）を 1 とした比率で判定します。値は目安なので、実機で試しながら調整してください。

| 項目 | 指標 | 範囲 |
| --- | --- | --- |
| 背すじ | 胴の垂直からの傾き | 20° 以下 |
| 床に座っている | ひざが腰よりどれだけ下か | 0.45 以下 |
| 脚を組んでいる | 足首が腰よりどれだけ下か（見えないときは省略） | 0.6 以下 |
| ひざが開いている | 左右のひざの間隔 | 0.7 以上 |
| 手の高さ | 手首が肩よりどれだけ下か | 0.6 以上 |
| 手の位置 | 手首の中点と体の中心の横ずれ | 0.5 以下 |
| 頭の位置 | 鼻と肩の中点の横ずれ | 0.35 以下 |

- 肩・腰・ひざが十分に見えないときは判定せず「全身が映るようにしてください」と表示します
- 表示のチラつきを抑えるため、OK/NG が 0.4 秒続いたときに切り替えます
- 骨格の点だけで判定しているため、呼吸や目線、骨盤の細かな傾きなどは判定できません

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # 判定ロジックのテスト
npm run build   # dist/ に出力
```

### Android 実機で試す

カメラは HTTPS か `localhost` でしか使えません。

- **USB 接続（すぐ試せる）**: PC で `npm run dev` → `adb reverse tcp:5173 tcp:5173` → Android の Chrome で `http://localhost:5173` を開く
- **GitHub Pages**: `main` に push すると `.github/workflows/deploy.yml` で公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）

## 構成

- `src/main.ts` … カメラ起動、MediaPipe Pose Landmarker の実行、描画
- `src/judge.ts` … ポーズ定義に沿った判定、表示の安定化
- `src/metrics.ts` … ランドマークから指標を計算
- `src/poses/` … ポーズ定義（データ）。ポーズを追加するときはここにファイルを足す
